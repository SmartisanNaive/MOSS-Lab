# @deepseek-ai/dsh-client-ui-sidebar-experiment

[English](README.md) | 中文

## 概述

当前会话的检查预览可用后，**实验动画**会自动打开并开始播放。也可从右侧栏引导页打开，或选择**查看演示**体验明确标识的演示数据。

<a id="implementation"></a>
## 实现

客户端每隔一秒检查当前会话的同源预览状态，每个新的检查任务自动打开一次；用户选择**重新检查**时再次检查。演示模式使用 `/api/experiment-demo` 和固定会话 `demo`，真实实验使用 `/api/experiment-preview`。两者均读取所选版本和任务的有限资源，再次确认状态后在沙盒框架中渲染。**查询机器人状态**单独发起一次只读请求，显示可用设备信息及查询时间。

<a id="model-experience"></a>
## 语音工作台

本地小智桥接只在首次打开、追问必要条件及当前预览完成时切到实验会话并打开实验区。普通改口及重复轮询保留用户选择。修改期间隐藏旧动画，只显示当前精确版本检查通过的预览，即使 Agent 仍在组织答复。缺失条件直接显示在面板中。认证桥接路由由本地 MOSS 启动配置提供。

当前检查通过的预览开始播放后，Agent 答复完成不会重新加载播放器。语音任务失败时只显示一次错误及下一步。同一请求已发布且仍通过当前检查的预览，在停止后续答复时继续保留；不可用或版本不匹配的预览仍隐藏。演示播放独立于语音任务状态，并保留明确的演示标签。

## 模型体验

无，本包只显示侧栏入口，不注册模型可见内容。

#### KV 缓存影响

无；页面不组装模型请求。
